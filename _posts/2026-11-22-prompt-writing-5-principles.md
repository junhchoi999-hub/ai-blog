같은 AI를 쓰는데 어떤 사람은 바로 쓸 수 있는 결과물을 받고, 어떤 사람은 뻔한 소리만 듣습니다. 차이는 대부분 **질문에 담긴 정보의 양**에서 납니다. AI는 내 상황을 모르기 때문에, 알려 주지 않은 부분은 가장 평범한 내용으로 채웁니다.

이 글에서는 ChatGPT, Claude, Gemini 어디에서나 통하는 다섯 가지 원칙을 예시와 함께 정리합니다.

## 1. 내 상황을 먼저 알려 준다

가장 효과가 큰 원칙입니다. 누가, 누구에게, 왜 필요한지를 적어 주세요.

**아쉬운 질문**

```
거래처에 보낼 납기 지연 메일 써 줘
```

**좋은 질문**

```
나는 중소 제조업체 영업 담당이야. 3년째 거래 중인 거래처 구매팀 과장님께
부품 납기가 원래 12월 5일에서 12월 12일로 일주일 늦어진다는 메일을 보내야 해.
원인은 원자재 입고 지연이고, 12월 8일에 절반을 먼저 보낼 수 있어.
정중하되 변명처럼 들리지 않게 써 줘.
```

두 번째 질문에는 관계, 날짜, 원인, 대안, 원하는 말투가 모두 들어 있습니다. AI가 지어낼 부분이 없으니 결과물을 거의 그대로 쓸 수 있습니다.

## 2. 원하는 결과물의 형태를 정해 준다

길이, 형식, 말투를 정하지 않으면 AI는 길고 무난한 글을 내놓습니다. 다음처럼 구체적으로 적어 보세요.

- **길이**: "300자 이내로", "세 문단으로"
- **형식**: "표로 정리해 줘", "번호 목록으로", "제목 5개만"
- **말투**: "초등학생도 이해하게", "보고서 문체로", "친근한 존댓말로"
- **독자**: "이 분야를 처음 접하는 신입사원이 읽을 거야"

특히 **독자가 누구인지** 알려 주면 설명의 깊이와 용어 수준이 한 번에 맞춰집니다.

## 3. 예시를 보여 준다

말로 설명하기 어려운 스타일은 예시 하나가 설명 열 줄보다 낫습니다.

```
아래는 우리 쇼핑몰 상품 설명 예시야. 같은 말투와 구조로 '스테인리스 텀블러' 설명을 써 줘.

[예시]
매일 쓰는 수건, 한 번 바꾸면 차이를 압니다.
40수 코마사로 짜서 처음부터 부드럽고, 세탁을 거듭해도 뻣뻣해지지 않습니다.
- 크기: 40×80cm
- 중량: 170g
```

예시는 한 개보다 두세 개가 좋습니다. 하나만 주면 AI가 그 예시를 지나치게 따라 하는 경향이 있습니다.

## 4. 큰 일은 단계로 나눈다

"사업계획서 써 줘"처럼 큰 요청을 한 번에 하면 전체가 얕아집니다. 순서를 나누면 각 단계의 품질이 올라가고, 중간에 방향을 고칠 수 있습니다.

1. "동네 반찬가게 온라인 판매 사업계획서의 목차부터 잡아 줘"
2. "2번 '시장 분석'을 먼저 써 줘. 내가 아는 정보는 다음과 같아…"
3. "방금 쓴 내용에서 근거가 약한 부분을 짚어 줘"

마지막처럼 **AI에게 자기 글을 검토시키는 것**도 좋은 방법입니다. 처음 쓸 때 놓친 빈틈을 꽤 잘 찾아냅니다.

## 5. 부족한 정보는 되묻게 한다

내가 무엇을 알려 줘야 할지 모를 때는 AI에게 질문을 시키세요.

```
이사 준비 체크리스트를 만들고 싶어.
만들기 전에 필요한 정보가 있으면 나에게 먼저 질문해 줘.
```

그러면 AI가 이사 날짜, 가족 구성, 포장이사 여부 등을 물어보고, 답을 바탕으로 내 상황에 맞는 결과를 만듭니다. 처음부터 완벽한 질문을 쓰려고 애쓸 필요가 없습니다.

## 그대로 쓸 수 있는 기본 틀

다섯 가지를 합치면 아래와 같은 틀이 됩니다. 필요한 칸만 채워서 쓰면 됩니다.

```
[상황] 나는 ○○이고, ○○를 하려고 해.
[요청] ○○를 만들어 줘.
[독자] 읽는 사람은 ○○야.
[형식] ○○ 분량으로, ○○ 형태로, ○○ 말투로.
[참고] 아래 예시/자료를 참고해 줘: …
[확인] 부족한 정보가 있으면 먼저 질문해 줘.
```

## 한 가지 주의할 점

질문을 아무리 잘해도 AI는 **사실이 아닌 내용을 그럴듯하게 말할 수 있습니다.** 통계 수치, 법률·세금, 날짜, 인용문처럼 틀리면 곤란한 내용은 반드시 원래 출처에서 다시 확인하세요. 프롬프트는 결과물의 형태와 방향을 잡아 주는 도구이고, 사실 확인까지 대신해 주지는 않습니다.

## 정리

| 원칙 | 한 줄 요약 |
|---|---|
| 상황 설명 | 누가, 누구에게, 왜 필요한지 적는다 |
| 형태 지정 | 길이, 형식, 말투, 독자를 정한다 |
| 예시 제공 | 원하는 스타일을 두세 개 보여 준다 |
| 단계 나누기 | 목차 → 부분 작성 → 검토 순으로 진행한다 |
| 되묻게 하기 | 필요한 정보를 AI가 먼저 질문하게 한다 |

처음에는 1번 하나만 지켜도 충분합니다. 질문 앞에 내 상황을 두세 문장 덧붙이는 것만으로 답변이 달라지는 것을 바로 확인할 수 있습니다.
