AI에게 질문했더니 존재하지 않는 책을 추천하거나, 틀린 통계를 자신 있게 말하는 경우가 있습니다. 이런 현상을 **환각(hallucination)**이라고 부릅니다. AI를 업무에 쓰려면 환각이 언제 잘 생기는지 알고, 걸러내는 습관을 들여야 합니다.

## 환각은 왜 생기나

생성형 AI는 사실을 저장한 데이터베이스에서 답을 꺼내 오는 방식으로 동작하지 않습니다. 학습한 방대한 글을 바탕으로 **앞 내용에 이어질 가능성이 높은 말**을 만들어 냅니다. 그래서 잘 모르는 내용에 대해서도 문장 자체는 매끄럽고 그럴듯하게 나옵니다.

중요한 점은 **말투의 자신감과 내용의 정확성이 별개**라는 것입니다. 틀린 답도 맞는 답과 똑같이 단정적인 문장으로 나오므로, 말투만 보고는 구분할 수 없습니다.

## 특히 틀리기 쉬운 질문 유형

다음 유형은 답을 받으면 반드시 따로 확인하세요.

| 유형 | 예 |
|---|---|
| 구체적인 숫자 | 통계, 가격, 점유율, 연도 |
| 출처와 인용 | 논문 제목, 판례 번호, 책 속 문장, 기사 링크 |
| 최신 정보 | 최근 바뀐 법·제도, 새로 나온 제품, 현재 요금제 |
| 덜 알려진 대상 | 작은 회사, 지역 정보, 유명하지 않은 인물 |
| 긴 계산 | 여러 단계를 거치는 암산, 큰 수의 곱셈 |
| 전문 분야의 판단 | 법률, 세금, 의료, 투자 |

반대로 글 다듬기, 요약, 번역, 아이디어 내기, 구조 잡기처럼 **내가 준 자료를 가공하는 작업**은 환각 위험이 상대적으로 낮습니다.

## 환각을 줄이는 질문법

### 1. 자료를 직접 준다

AI의 기억에 의존하게 하지 말고, 근거가 되는 문서를 붙여 넣거나 파일로 올린 뒤 그 안에서만 답하게 하세요.

```
아래 계약서 내용만 근거로 답해 줘.
계약서에 없는 내용이면 "문서에 없음"이라고 말해 줘.

[계약서 내용 붙여넣기]

질문: 중도 해지 시 위약금은 얼마야?
```

### 2. 모르면 모른다고 말하게 한다

```
확실하지 않은 내용은 추측하지 말고 "확실하지 않음"이라고 표시해 줘.
```

이 한 줄만으로도 억지로 지어내는 경우가 줄어듭니다. 완전히 없어지지는 않으니 확인은 여전히 필요합니다.

### 3. 근거를 함께 요구한다

```
각 주장마다 문서의 어느 부분을 근거로 했는지 원문을 인용해서 보여 줘.
```

인용된 문장을 원문에서 찾아보면 맞는지 바로 확인할 수 있습니다. 내가 준 자료가 아닌 외부 출처(논문, 기사)를 대라고 하면 **출처 자체를 지어낼 수 있다**는 점은 기억하세요. 제목과 저자가 그럴듯해도 실제로 존재하는지 검색해 봐야 합니다.

### 4. 웹 검색 기능을 켠다

주요 AI 서비스는 웹 검색 기능을 제공합니다. 최신 정보나 사실 확인이 필요한 질문에는 검색을 사용하게 하고, 답변에 달린 링크를 직접 열어 해당 내용이 실제로 있는지 확인하세요. 링크가 달려 있다고 해서 내용이 정확하다는 뜻은 아닙니다. AI가 페이지 내용을 잘못 요약하는 경우도 있습니다.

### 5. 계산은 도구에 맡긴다

복잡한 계산은 AI에게 답만 묻지 말고 **엑셀 수식이나 계산 과정**을 요청한 뒤, 엑셀이나 계산기로 직접 돌려 보세요. 코드 실행 기능이 있는 서비스라면 "코드를 실행해서 계산해 줘"라고 요청하는 것도 방법입니다.

## 검증 체크리스트

AI의 답을 다른 사람에게 전달하거나 문서에 넣기 전에 다음을 확인하세요.

- 숫자와 날짜를 원래 출처에서 확인했는가
- 인용한 논문, 법 조항, 기사 등이 실제로 존재하는가
- 정보의 기준 시점이 언제인가, 그 뒤로 바뀌지 않았는가
- 법률·세금·의료처럼 틀리면 피해가 큰 내용인가 (그렇다면 공식 기관이나 전문가에게 확인)
- 같은 질문을 새 대화에서 다시 했을 때도 같은 답이 나오는가

마지막 항목은 간단하지만 쓸 만한 방법입니다. 지어낸 내용은 물을 때마다 달라지는 경우가 많습니다. 다만 답이 일관되더라도 틀릴 수 있으므로 보조 수단으로만 쓰세요.

## 어디까지 믿어야 하나

AI를 **아는 것이 많지만 가끔 착각하는 동료**로 생각하면 적당합니다. 초안 작성, 정리, 아이디어 제안은 맡기되, 사실관계에 대한 최종 책임은 사용하는 사람에게 있습니다. 실제로 AI가 지어낸 판례를 그대로 법원에 제출했다가 문제가 된 사례가 해외에서 여러 차례 보도되었습니다.

## 정리

- AI는 그럴듯한 문장을 만드는 도구이며, 자신 있는 말투가 정확성을 보장하지 않는다.
- 숫자, 출처, 최신 정보, 전문 분야 판단은 반드시 따로 확인한다.
- 근거 자료를 직접 주고, 모르면 모른다고 말하게 하면 환각이 줄어든다.
- 중요한 내용은 원래 출처나 공식 기관에서 한 번 더 확인한다.
