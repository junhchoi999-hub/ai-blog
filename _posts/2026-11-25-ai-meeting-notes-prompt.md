AI 회의록 정리는 직장인이 AI를 가장 먼저 써 보는 일 가운데 하나입니다. 그런데 "프롬프트를 자세히 써야 한다"는 말이 실제로 얼마나 차이를 만드는지는 직접 해 보기 전에는 알기 어렵습니다. 그래서 같은 회의 내용을 **한 줄 요청**과 **조건을 넣은 요청**으로 각각 실행해 결과를 비교했습니다. 이 글에는 두 결과를 고치지 않고 그대로 실었고, 그 비교에서 얻은 회의록 프롬프트를 정리했습니다. 챗GPT(ChatGPT), Claude, Gemini 어디에서나 쓸 수 있습니다.

## 실험 방법

실험에는 일부러 **허점이 있는 회의**를 사용했습니다. 실제 회의처럼 담당자가 정해지지 않은 일, 서로 엇갈린 기억, 애매한 기한을 넣어 만든 가상의 회의입니다.

- **실행일**: 2026년 11월 25일
- **사용한 AI**: Claude. 두 요청을 서로 영향을 주지 않도록 각각 새 대화에서 한 번씩 실행했습니다.
- **표기**: 결과의 문장은 고치지 않았고, 굵은 글씨 표시와 표 구분선 같은 서식 기호만 읽기 쉽게 정리했습니다.
- **주의**: AI의 답은 실행할 때마다 조금씩 달라집니다. 아래 결과는 한 번씩 실행한 것이므로 "항상 이렇게 나온다"는 뜻은 아닙니다.

### 사용한 회의 내용 (가상)

```
김 팀장: 자, 12월 프로모션 얘기부터 하죠. 지난번에 할인율 15%로 가자고 했었나요?
박 대리: 저는 20%로 들었는데요. 작년에 20%로 했을 때 반응이 좋았어서.
김 팀장: 음, 그건 재무팀이랑 한 번 더 확인해 봐야겠네요. 일단 넘어가죠.
이 사원: 배너 시안은 제가 만들고 있고요, 다음 주 중에는 될 것 같습니다.
김 팀장: 좋아요. 뉴스레터는 누가 하죠?
박 대리: 지난번엔 최 주임이 했는데 오늘 휴가라서요.
김 팀장: 그럼 그건 누가 물어봐 주세요. 그리고 행사 시작일은 12월 7일로 확정합시다.
박 대리: 네. 근데 상세페이지 수정은 개발팀 일정이 걸려 있어서, 늦어도 금요일까지는 요청해야 해요.
김 팀장: 그건 박 대리가 요청해 주세요.
박 대리: 알겠습니다.
이 사원: 아, 그리고 지난달 구매 후기 이벤트 당첨자 발표가 아직 안 나갔습니다.
김 팀장: 그거 급하네요. 빨리 처리합시다. 오늘은 여기까지 하죠.
```

이 회의에 숨겨 둔 허점은 다섯 가지입니다.

1. 할인율이 15%인지 20%인지 엇갈렸고, 재무팀에 **누가** 확인할지 정하지 않았다.
2. 뉴스레터를 "누가 물어봐 주세요"라고만 하고 **물어볼 사람**을 정하지 않았다.
3. 당첨자 발표는 "빨리 처리합시다"뿐, **담당자와 기한**이 없다.
4. "금요일"이 **어느 금요일**인지 날짜가 없다.
5. 배너 시안의 "다음 주 중"은 확정이 아닌 **예상**이다.

## 요청 1: "이 회의 내용 정리해 줘"

첫 번째는 아무 조건 없이 한 줄만 쓴 요청입니다.

```
이 회의 내용 정리해 줘.

(회의 내용)
```

**받은 결과 (그대로)**

```
## 12월 프로모션 회의 정리

참석자: 김 팀장, 박 대리, 이 사원 (최 주임 휴가로 불참)

### 확정된 것
- 행사 시작일은 12월 7일입니다.
- 상세페이지 수정은 박 대리가 개발팀에 요청합니다. 기한은 늦어도 금요일입니다.

### 확정되지 않은 것
- 할인율: 김 팀장은 15%, 박 대리는 20%로 기억하고 있습니다. 재무팀에 확인하기로
  했지만 누가 확인할지는 정하지 않았습니다.
- 뉴스레터 담당자: 지난번에는 최 주임이 맡았습니다. 이번에도 맡을지 "누가 물어봐
  달라"고만 했고, 물어볼 사람은 정하지 않았습니다.
- 구매 후기 이벤트 당첨자 발표: 지난달 것이 아직 안 나갔습니다. 급하다고만 하고
  담당자와 기한은 정하지 않았습니다.

### 할 일
| 할 일 | 담당 | 기한 |
| 상세페이지 수정을 개발팀에 요청 | 박 대리 | 늦어도 금요일 |
| 배너 시안 제작 | 이 사원 | 다음 주 중 (예상) |
| 할인율(15% 또는 20%)을 재무팀에 확인 | 미정 | 미정 |
| 최 주임에게 뉴스레터 담당 여부 확인 | 미정 | 미정 |
| 지난달 구매 후기 이벤트 당첨자 발표 | 미정 | 미정 (급함) |

### 먼저 정해야 할 것
- 담당자가 없는 세 가지 일을 누가 맡을지 정해야 합니다. 당첨자 발표가 가장 급합니다.
- "금요일"이 이번 주 금요일인지 날짜로 확인해야 합니다.
- 배너 시안의 "다음 주 중"은 예상이므로, 12월 7일 시작에 맞는 마감일을 정해야 합니다.
```

한 줄 요청인데도 결과가 예상보다 좋았습니다. 숨겨 둔 허점 다섯 가지를 모두 짚었고, 정해지지 않은 담당자를 지어내지 않고 "미정"으로 적었습니다.

## 요청 2: 읽을 사람, 형식, 조건을 넣은 요청

두 번째는 읽을 사람과 형식을 정하고, 추측하지 말라는 조건을 넣은 요청입니다.

```
아래는 마케팅팀 주간 회의를 받아 적은 내용이야. 회의에 참석하지 않은 팀원도
읽고 바로 움직일 수 있게 회의록으로 정리해 줘.

- 형식: 1) 결정된 사항 2) 할 일 표(할 일 / 담당자 / 기한) 3) 결정되지 않은 사항
- 회의 내용에 적힌 것만 근거로 써 줘. 담당자나 기한이 회의에서 정해지지 않았으면
  추측하지 말고 "미정"이라고 적어 줘.
- 참석자끼리 말이 엇갈린 부분은 누가 뭐라고 했는지 그대로 적어 줘.
- 마지막에 "확인이 필요한 질문"을 따로 뽑아 줘.

[회의 내용]
(회의 내용)
```

**받은 결과 (그대로)**

```
# 마케팅팀 주간 회의록

- 참석: 김 팀장, 박 대리, 이 사원 (최 주임은 휴가로 불참)
- 안건: 12월 프로모션 준비, 지난달 구매 후기 이벤트

## 1) 결정된 사항
- 행사 시작일은 12월 7일로 확정했습니다.
- 상세페이지 수정은 박 대리가 개발팀에 요청합니다. 개발팀 일정 때문에 늦어도
  금요일까지는 요청해야 합니다(박 대리 발언).
- 배너 시안은 이 사원이 제작 중입니다. 이 사원은 "다음 주 중에는 될 것 같다"고
  했습니다.
- 지난달 구매 후기 이벤트 당첨자 발표는 빨리 처리하기로 했습니다. 아직 발표가
  나가지 않은 상태이며, 담당자와 기한은 정하지 않았습니다.

## 2) 할 일
| 할 일 | 담당자 | 기한 |
| 상세페이지 수정을 개발팀에 요청 | 박 대리 | 늦어도 금요일 (날짜는 언급 없음) |
| 배너 시안 제작 | 이 사원 | 다음 주 중 (이 사원의 예상, 확정 날짜 없음) |
| 12월 프로모션 할인율을 재무팀에 확인 | 미정 | 미정 |
| 뉴스레터 건을 최 주임에게 문의 | 미정 (김 팀장이 "누가 물어봐 주세요"라고만 함) | 미정 |
| 뉴스레터 제작 | 미정 | 미정 |
| 지난달 구매 후기 이벤트 당첨자 발표 | 미정 | 미정 ("빨리 처리"라고만 함) |

## 3) 결정되지 않은 사항
- 12월 프로모션 할인율: 참석자 간 기억이 엇갈렸고, 결론 없이 넘어갔습니다.
  - 김 팀장: "지난번에 할인율 15%로 가자고 했었나요?"
  - 박 대리: "저는 20%로 들었는데요. 작년에 20%로 했을 때 반응이 좋았어서."
  - 김 팀장: 재무팀과 한 번 더 확인해 봐야겠다고 하고 다음 안건으로 넘어갔습니다.
- 뉴스레터 담당자: 지난번에는 최 주임이 했으나 오늘 휴가여서 정하지 못했습니다.
- 구매 후기 이벤트 당첨자 발표의 담당자와 일정: 급하다는 데는 의견이 모였지만
  누가 언제까지 할지는 정하지 않았습니다.

## 확인이 필요한 질문
1. 12월 프로모션 할인율은 15%와 20% 중 무엇입니까? 재무팀 확인은 누가, 언제까지 합니까?
2. 최 주임에게는 누가 연락합니까? 이번 뉴스레터도 최 주임이 맡습니까?
3. 뉴스레터는 언제까지 준비되어야 합니까?
4. 구매 후기 이벤트 당첨자 발표는 누가, 언제까지 합니까?
5. 상세페이지 수정 요청 기한인 "금요일"은 이번 주 금요일입니까?
6. 배너 시안의 정확한 마감일은 언제입니까?
```

## 두 결과를 비교하면

두 결과 모두 담당자나 기한을 지어내지 않았습니다. 차이는 **얼마나 빠짐없이, 얼마나 예측 가능한 형식으로** 나왔는가에 있었습니다.

| 비교 항목 | 한 줄 요청 | 조건을 넣은 요청 |
|---|---|---|
| 숨겨 둔 허점 5가지 | 모두 짚음 | 모두 짚음 |
| 담당자·기한 지어내기 | 없음 | 없음 |
| 할 일 개수 | 5개 | 6개 ("뉴스레터 제작"을 따로 분리) |
| 엇갈린 발언 | 요약해서 전달 | 누가 뭐라고 했는지 원문 인용 |
| 확인할 질문 | 3개 (묶어서) | 6개 (일마다 하나씩) |
| 형식 | AI가 알아서 정함 | 요청한 순서 그대로 |

조건을 넣은 요청에서 눈에 띄는 차이는 세 가지였습니다.

- **빠진 일을 찾아냈습니다.** "최 주임에게 물어보기"와 별개로 "뉴스레터를 만드는 일" 자체에 담당자가 없다는 점은 조건을 넣은 요청에서만 나왔습니다.
- **질문이 바로 보낼 수 있는 형태로 나왔습니다.** 여섯 개 질문을 그대로 팀 메신저에 올리면 됩니다.
- **형식이 고정됩니다.** 매주 같은 프롬프트를 쓰면 회의록 모양이 같아져 지난 회의록과 비교하기 쉽습니다. 한 줄 요청은 실행할 때마다 구성이 달라질 수 있습니다.

조건을 넣은 요청에도 아쉬운 점이 있었습니다. 담당자도 기한도 없는 "당첨자 발표를 빨리 처리하기로 함"을 **결정된 사항**에 넣었습니다. 사람이 보기에는 결정이라기보다 미결에 가깝습니다. 한 줄 요청은 같은 내용을 "확정되지 않은 것"으로 분류했습니다. AI가 무엇을 "결정"으로 볼지는 실행마다 달라질 수 있다는 뜻이고, 그래서 사람의 확인이 필요합니다.

정리하면, 이번처럼 짧은 회의에서는 한 줄 요청도 충분히 쓸 만했습니다. 조건을 넣는 이유는 결과가 "틀리지 않게" 하기 위해서라기보다 **빠진 일을 줄이고, 매번 같은 형식으로 받기 위해서**였습니다. 회의가 길어지고 참석자가 많아질수록 이 차이는 커질 가능성이 높지만, 그 부분은 이번 실험에서 확인하지 않았습니다.

## 바로 쓸 수 있는 회의록 프롬프트

실험에 사용한 프롬프트를 다른 회의에도 쓸 수 있게 다듬었습니다. 대괄호 안만 바꿔서 쓰세요.

```
아래는 [팀 이름]의 [회의 이름]을 받아 적은 내용이야.
회의에 참석하지 않은 사람도 읽고 바로 움직일 수 있게 회의록으로 정리해 줘.

- 형식: 1) 결정된 사항 2) 할 일 표(할 일 / 담당자 / 기한) 3) 결정되지 않은 사항
- 담당자와 기한이 모두 정해진 것만 "결정된 사항"에 넣어 줘.
- 회의 내용에 적힌 것만 근거로 써 줘. 정해지지 않은 담당자나 기한은
  추측하지 말고 "미정"이라고 적어 줘.
- "다음 주", "금요일"처럼 날짜가 분명하지 않은 표현은 그대로 적고 표시해 줘.
- 참석자끼리 말이 엇갈린 부분은 누가 뭐라고 했는지 그대로 적어 줘.
- 마지막에 "확인이 필요한 질문"을 일마다 하나씩 뽑아 줘.

[회의 내용 붙여넣기]
```

두 번째 줄의 "담당자와 기한이 모두 정해진 것만 결정된 사항에 넣어 줘"는 이번 실험에서 발견한 아쉬운 점을 보완하려고 추가한 조건입니다. 이 문구를 넣은 프롬프트는 따로 실행해 보지 않았으니, 처음 쓸 때 결과를 확인해 보세요.

## 공유하기 전에 확인할 것

AI가 만든 회의록은 아래 순서로 확인한 뒤에 공유하세요.

![AI 회의록 정리 순서: 회의 내용 준비, 프롬프트로 정리, 원문과 대조, 팀에 공유]({{ '/assets/images/ai-meeting-notes-prompt/steps.png' | relative_url }}){: width="1200" height="476" loading="lazy"}

- **담당자와 기한**: 표의 각 줄을 회의 원문에서 찾아 맞는지 봅니다. 가장 자주 틀리고, 틀리면 가장 곤란한 부분입니다.
- **숫자**: 금액, 비율, 날짜가 원문과 같은지 확인합니다.
- **"결정"으로 분류된 항목**: 정말 결정된 것인지, 말만 나온 것인지 봅니다.
- **빠진 안건**: 회의에서 다룬 주제가 모두 들어 있는지 훑어봅니다. 회의가 길수록 중요합니다.

회의를 녹음해서 쓸 계획이라면 녹음 전에 참석자에게 알리고 동의를 구하세요. 회사에 녹음이나 AI 사용에 관한 규정이 있다면 그 규정이 우선입니다. 고객 정보나 미공개 실적처럼 민감한 내용은 AI에 넣기 전에 빼거나 가명으로 바꾸는 것이 안전합니다.

AI가 원문에 없는 내용을 덧붙이는 경우와 그 확인 방법은 [AI가 틀린 답을 당당하게 말할 때: 환각 줄이는 법과 확인 방법]({% post_url 2026-11-22-ai-hallucination-check %})에서 더 자세히 다룹니다.
