엑셀 수식은 가끔 쓰면 매번 문법을 잊어버립니다. 이럴 때 AI에게 물으면 검색보다 훨씬 빠릅니다. 다만 "수식 만들어 줘"라고만 하면 내 파일과 맞지 않는 수식이 나옵니다. **표가 어떻게 생겼는지** 알려 주는 것이 핵심입니다.

## 질문에 꼭 넣어야 할 세 가지

1. **데이터 위치** — 어느 시트의 어느 열에 무엇이 들어 있는지
2. **원하는 결과** — 어느 셀에 무엇이 나와야 하는지
3. **사용 환경** — 엑셀 버전, 또는 구글 스프레드시트인지

버전이 중요한 이유는 `XLOOKUP`, `FILTER`, `UNIQUE` 같은 함수가 Microsoft 365와 엑셀 2021 이상에서만 동작하기 때문입니다. 구버전을 쓴다면 반드시 알려 주세요.

## 예시 1: 다른 시트에서 값 찾아오기

**질문**

```
엑셀 365를 써.
'주문' 시트: A열 주문번호, B열 상품코드, C열 수량
'상품' 시트: A열 상품코드, B열 상품명, C열 단가
'주문' 시트 D2에 B2의 상품코드에 해당하는 단가를 가져오는 수식을 알려 줘.
상품코드가 없으면 "미등록"이라고 표시해 줘.
```

**AI가 주는 답 (예)**

```
=XLOOKUP(B2, 상품!A:A, 상품!C:C, "미등록")
```

구버전이라고 알려 주면 같은 기능을 다음처럼 바꿔 줍니다.

```
=IFERROR(VLOOKUP(B2, 상품!A:C, 3, FALSE), "미등록")
```

`VLOOKUP`의 마지막 인수 `FALSE`는 정확히 일치하는 값만 찾으라는 뜻입니다. 이 인수를 빼면 엉뚱한 값이 나올 수 있으니, AI가 준 수식에 들어 있는지 확인하세요.

## 예시 2: 여러 조건으로 합계 구하기

**질문**

```
A열 날짜, B열 담당자, C열 지역, D열 매출액이야. 데이터는 2행부터 500행까지.
담당자가 "김민수"이고 지역이 "부산"인 매출 합계를 구하는 수식을 알려 줘.
```

**답**

```
=SUMIFS(D2:D500, B2:B500, "김민수", C2:C500, "부산")
```

여기에 "2026년 10월 한 달만"이라는 조건을 추가하고 싶다면 그대로 이어서 물으면 됩니다.

```
=SUMIFS(D2:D500, B2:B500, "김민수", C2:C500, "부산",
        A2:A500, ">="&DATE(2026,10,1), A2:A500, "<"&DATE(2026,11,1))
```

날짜 조건은 직접 쓰기 까다로운 부분이라 AI의 도움이 특히 유용합니다.

## 예시 3: 텍스트 나누고 합치기

**질문**

```
A열에 "홍길동(영업1팀)" 형식으로 들어 있어.
B열에 이름만, C열에 팀 이름만 뽑는 수식을 각각 알려 줘. 엑셀 2019야.
```

**답**

```
B2: =LEFT(A2, FIND("(", A2) - 1)
C2: =MID(A2, FIND("(", A2) + 1, FIND(")", A2) - FIND("(", A2) - 1)
```

실제 데이터 두세 줄을 그대로 붙여 넣어 보여 주면 정확도가 더 올라갑니다. 단, **개인정보나 회사 기밀이 담긴 데이터는 가짜 값으로 바꿔서** 붙여 넣으세요.

## 수식이 안 될 때 물어보는 법

오류가 나면 수식과 오류 메시지, 그리고 실제 셀 값을 함께 알려 주세요.

```
=VLOOKUP(B2, 상품!A:C, 3, FALSE) 를 넣었는데 #N/A 가 나와.
B2 값은 1001 이고, 상품 시트 A열에도 1001 이 분명히 있어.
```

이 경우 AI는 흔한 원인을 짚어 줍니다. 한쪽은 숫자이고 다른 쪽은 문자로 저장된 경우, 값 앞뒤에 공백이 숨어 있는 경우가 대표적입니다. 자주 만나는 오류의 의미는 다음과 같습니다.

| 오류 | 의미 |
|---|---|
| `#N/A` | 찾는 값이 없음 |
| `#VALUE!` | 숫자가 필요한 자리에 문자가 들어감 |
| `#REF!` | 참조하던 셀이나 범위가 삭제됨 |
| `#DIV/0!` | 0으로 나눔 |
| `#NAME?` | 함수 이름이 틀렸거나 해당 버전에 없는 함수 |

## 받은 수식은 반드시 검증한다

AI가 준 수식이 오류 없이 값을 내놓는다고 해서 **맞는 값**이라는 보장은 없습니다. 다음 순서로 확인하세요.

1. **손으로 계산 가능한 두세 건과 비교한다.** 필터로 직접 걸러 합계를 낸 값과 수식 결과가 같은지 봅니다.
2. **경계 조건을 넣어 본다.** 빈 셀, 값이 없는 경우, 날짜의 첫날과 마지막 날이 제대로 처리되는지 확인합니다.
3. **수식을 설명하게 한다.** "이 수식을 부분별로 설명해 줘"라고 하면 내 의도와 다른 부분을 찾기 쉽습니다.

수식을 이해하지 못한 채 보고서에 쓰는 것은 위험합니다. 설명을 한 번 듣고 넘어가면 다음에 수정할 때도 훨씬 수월합니다.

## 정리

- 표 구조(시트, 열, 행 범위)와 원하는 결과, 엑셀 버전을 함께 알려 준다.
- 오류가 나면 수식, 오류 메시지, 실제 값을 같이 보여 준다.
- 민감한 데이터는 가짜 값으로 바꿔서 붙여 넣는다.
- 받은 수식은 직접 계산한 값과 비교해 검증한다.

수식 문법을 외우는 데 쓰던 시간을, 어떤 결과가 필요한지 정리하는 데 쓰면 됩니다.
